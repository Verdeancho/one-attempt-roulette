# Changelog

## v1.3.0
- The mod is now called **One Attempt Roulette**, with a new logo.
- Notifications (level results, warnings, statistics, errors) can be moved and turned on or off per type, in the new **Notifications** tab of the editor. By default they appear a bit lower.
- The main roulette menu is slightly smaller so it fits better on screen.

## v1.2.0
- **Force popular levels** now uses the most downloaded levels with a **minimum number of downloads** (default 100K).
- Popular roulettes are grouped inside each difficulty, in a new **Popular** tab of its history.

## v1.1.0
- New **Force popular levels** option for difficulty roulettes: most liked levels first, with many well-known levels.

## v1.0.0
- First public version.
- Difficulty, Demonlist and Specials roulettes (recent, random, friends, gamemode challenges, The Challenge List).
- Classic / Platformer / Both filter.
- In-game overlay with live total and mean, movable and with custom colors.
- Level screen panel, graphs, statistics with records, history, locks and deletion.
- In-game "How to use" guide and credits.
- Optional OBS text files.
